# Agenda Bella
Protótipo de um sistema web para agendamento de serviços de manicure, desenvolvido como projeto acadêmico (PIM) do curso de Análise e Desenvolvimento de Sistemas.

# Sobre o Projeto
O Agenda Bella foi desenvolvido com o objetivo de demonstrar a aplicação de conceitos de desenvolvimento web utilizando a arquitetura MVC. O sistema simula o funcionamento de uma plataforma de agendamento para uma profissional da área de manicure.

# Funcionalidades Implementadas
# Área do Cliente
* Login e cadastro
* Recuperação de senha
* Agendamento de serviços
* Visualização de agendamentos
* Tela de confirmação de agendamento

# Área Administrativa
* Dashboard administrativo
* Agenda diária
* Cadastro de horários
* Controle de horários
* Cadastro de serviços
* Listagem de serviços

# Tecnologias Utilizadas
* ASP.NET Core MVC
* C#
* HTML5
* CSS3
* JavaScript
* Bootstrap

# Arquitetura Utilizada
O projeto segue o padrão MVC (Model-View-Controller):

* **Models:** representam os dados da aplicação.
* **Views:** responsáveis pela interface do usuário.
* **Controllers:** controlam as requisições e regras de navegação.

# Responsividade
A interface foi desenvolvida utilizando Bootstrap 5 e CSS personalizado, permitindo adaptação para dispositivos móveis, tablets e computadores.
